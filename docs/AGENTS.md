# DSH Dashboard · AI 使用说明（插件自动注入）

用户要看数据看板/图表/可视化时，优先调用 render_dashboard 工具。

## 视觉层级（AI 布局思考）

生成 config 时先问"用户最想看什么"——回答主要问题的图表设 grid.w=16（主角），辅助图表设 grid.w=8（配角），错落有致不要等宽排队。

## 交付时必须附使用说明
